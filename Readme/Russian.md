# Что это?

### Это фреймворк для создания и управления кастомных голосований. Вы можете создать голосование при помощи:

1. Дополнение кода текущего плагина.
2. Наследования класса ```VoteBase``` или ```VoteAction``` в вашем плагине и регистрации при помощи ```VoteManager.AddVoteBase(VoteBase base);```
3. Вызвать начало голосования в нужный вам момент при помощи ```VoteManager.StartVote<T>()```

#### Пример вы можете найти в ```Votings/VotingFriendlyFire```

##### Базовое голосование за включение Friendly Fire вначале раунда добавлено. Для отключения голосования за огонь по своим вам необходимо изменить конфиг ```Config - VotingFF - IsEnabled - false```.
